# Análise de Dados com Python

Este repositório reúne duas atividades que fiz durante meus estudos de Análise de Dados.

## Atividades

### 1. Análise de Vendas de Café
Exercício feito em aula, utilizando Python para organizar os dados, consultar algumas informações estatísticas e criar um gráfico para comparar a temperatura com as vendas de café.

### 2. O Mistério do Bônus de Vendas
Mini-case proposto como desafio, no qual analisei as vendas de cinco vendedores para entender a diferença entre média e mediana e o impacto de um valor muito alto nos resultados.

## Ferramentas utilizadas

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
