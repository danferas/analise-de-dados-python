# Análise de Dados com Python 📊

Aqui estão duas atividades que fiz durante meus estudos de Análise de Dados. Uma foi feita em aula e a outra foi um mini-case proposto como desafio.

## 1. Análise de Vendas de Café

Esse exercício foi feito em aula. Trabalhamos com uma tabela que mostra a quantidade de cafés vendidos e a temperatura em cada dia da semana.

Usei Python para organizar os dados, visualizar algumas informações e criar um gráfico para comparar a temperatura com as vendas de café.

## 2. O Mistério do Bônus de Vendas

Esse foi um mini-case para colocar em prática o que estamos aprendendo.

A situação apresenta as vendas de cinco vendedores, mas um deles conseguiu fazer uma venda bem maior que as outras. O desafio era entender como isso afetava a média e se ela seria uma boa referência para definir a meta de todos.

Para analisar os dados, calculei a média, a mediana e a amplitude, além de criar um Box Plot.

## Ferramentas utilizadas

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
